What is in file 1

Most state tax tables stop at income tax. File 1 covers the rest of the paycheck. 14 states have at least one employee-paid program in our calculators, 20 programs in all. 34 states show None modeled and link to the state page with its sources. Hawaii and New Mexico list items our calculators do not subtract (see the note under the table).

Column dictionary

File 1: payroll withholding

ColumnMeaning
scopefederal (same in every state) or state.
state, state_abbrState name and postal abbreviation. Federal rows use All states and US.
programThe withholding. One row per program per state. None modeled means the calculator withholds no employee-paid state payroll program there.
categoryunemployment, disability, paid_family_medical_leave, long_term_care, transit, workers_benefit, social_security, medicare, other.
in_calculator_netyes if our calculator subtracts it from take-home pay. no for optional or unmodeled items we list for completeness.
rate_percentEmployee rate as a percent of wages (0.807159 means 0.807159%). For optional items, the most an employer may withhold.
wage_cap_usd_per_yearWages above this amount are not subject to the charge. Empty means no cap.
flat_amount_usd, flat_basisFor programs charged as a fixed amount rather than a rate, the amount and what it is charged per.
max_per_year_usdThe most one employee pays in a year, where a cap or a fixed amount makes it knowable. Empty where there is no cap.
source_urlThe official document that carries the rate.
source_checked_onThe date we last confirmed the link loaded and still showed the figure.
state_page_urlOur calculator page for the state, which names every source it uses. Federal rows point to the methodology page.
notesContext a reader needs to use the row correctly.

File 2: take-home pay

ColumnMeaning
state, state_abbrState name and postal abbreviation.
gross_salary_usdAnnual pay before tax: 40,000, 60,000, 75,000, 100,000 or 150,000.
filing_statusAlways single.
federal_income_tax_usdFederal income tax after the 2026 standard deduction.
social_security_usd, medicare_usdFederal payroll taxes (FICA), employee share.
state_income_tax_usdState income tax withholding. Zero in the nine states with no wage tax.

Limits you should know

  • Take-home pay is for a single filer with no 401(k) and the standard deduction.
  • Local income taxes are not included, except the default county in Indiana and Maryland.
  • Employer-paid taxes are not included. Where a state lets employers choose how much to withhold, the file uses the maximum and says so in notes.
  • None modeled describes our calculator, not the law. Check the state page.
  • Rates are for 2026. Federal rates were verified August 22, 2026; each source link carries its own check date in the file, between September 30, 2026 and October 27, 2026.

Versions and corrections

We re-verify every rate each January; the next review is January 15, 2027. If a figure is wrong, the file and its version number change and the change is written up on the corrections page. Method and sources: methodology. To report a problem, contact us.
